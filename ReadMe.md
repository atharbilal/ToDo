# To-Do List App in JavaFX

A simple **To-Do List application** built using **JavaFX**. It allows users to add tasks, mark them as done, and provides a friendly greeting.

## Features

- Prompt the user for their name and display a personalized greeting.
- Add new tasks to a dynamic to-do list.
- Mark tasks as completed with a green tick and bold text.
- User-friendly interface with input field, buttons, and a list view.


### Requirements

- Java 8 or higher
- JavaFX SDK (if using Java 11+)
- IDE like IntelliJ IDEA, Eclipse, or command-line setup
